# Code of Conduct

## Our pledge

We want ProbAI to be a welcoming project for everyone, regardless of experience level, background, identity, or nationality.

## Expected behaviour

- Be respectful and constructive, especially in code review.
- Assume good intentions and ask questions before criticising.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults, discrimination, or personal attacks.
- Publishing other people's private information.
- Spam, trolling, or deliberately disruptive behaviour.

## Enforcement

Maintainers may edit or remove comments, commits, issues, and other contributions that violate this code, and may temporarily or permanently ban contributors for behaviour they judge inappropriate. To report a problem, open an issue marked "conduct" without private details, or contact a maintainer through their GitHub profile.

This code of conduct is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
